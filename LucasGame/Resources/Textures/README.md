# Textures Directory

This directory contains all the texture files for the game, including:

- Character textures
- Weapon textures
- Building textures
- Environment textures
- UI textures

## Texture Formats

- .png - For UI and simple textures
- .jpg - For environment textures
- .dds - For compressed textures
- .tga - For high-quality textures

## Resolution

All textures are designed for 8K resolution (7680x4320) to support the game's high-quality graphics.
