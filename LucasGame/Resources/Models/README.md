# Models Directory

This directory contains all the 3D model files for the game, including:

- Character models
- Weapon models
- Building models
- Environment models
- Vehicle models

## Model Formats

- .fbx - Main model format
- .obj - Alternative model format
- .dae - Collada format
- .glb - GLTF binary format

## Quality

All models are designed with high polygon counts and detailed textures to support 8K resolution rendering.
