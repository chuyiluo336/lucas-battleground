# Sounds Directory

This directory contains all the sound files for the game, including:

- Weapon sounds
- Character sounds
- Environment sounds
- Music
- UI sounds

## Sound Formats

- .wav - High-quality uncompressed audio
- .mp3 - Compressed audio for music
- .ogg - Compressed audio for sound effects

## Quality

All sounds are designed with high quality to enhance the immersive gaming experience.
